# Project Context

**One-line pitch:** Sentinel is a full-stack AI Security & Privacy Assistant that analyzes content for risks and PII before you send it.

**Problem statement:** Users frequently overshare sensitive information (PII) or fall victim to social-engineering tactics without realizing it. There is a need for a seamless tool that intercepts, analyzes, and redacts content to ensure privacy and safety before sharing.

**4 Core Features:**
1. **Real-time Threat Detection Pipeline:** Analyzes pasted content for PII and social-engineering signals.
2. **Actionable Feedback:** Returns a risk score (0-100) and plain-language flags explaining detected risks.
3. **Safe Redaction:** Provides a redacted, safe-to-send version of the content.
4. **Audit Trail:** Logs all analysis history and scores to a secure database for review.
